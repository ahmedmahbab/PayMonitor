# Al Nour Pay Monitor — نسخة اختبار يدوية

هذه نسخة تجريبية لا تطلب RECEIVE_SMS ولا READ_SMS، ولا تستخدم BroadcastReceiver. لا تستطيع قراءة الرسائل تلقائياً.

## التثبيت

ارفع **محتويات مجلد android** إلى المستودع تحت مسار android مع الحفاظ على البنية، أو استبدل الملفات التي تغيرت:
- `android/app/src/main/AndroidManifest.xml`
- `android/app/src/main/java/dz/alnourelite/paymonitor/MainActivity.kt`
- `android/app/build.gradle.kts`

شغّل GitHub Actions لبناء `app-debug.apk` جديد. لا تستخدم APK القديم الذي حجبه Play Protect، ولا تتجاوز الحظر.

## طريقة الاستخدام

1. ثبّت النسخة الجديدة بعد التأكد من عدم طلب SMS permissions.
2. أدخل رابط HTTPS ومفتاح الجهاز، ولا ترسل المفتاح إلى أي شخص أو GitHub.
3. انسخ **إشعار الإيداع فقط** إلى خانة النص (وليس OTP) وراجع المبلغ.
4. أرسل للاختبار، ثم تحقق من ظهوره في لوحة الويب.

## قيود أمنية وتشغيلية

- الرسائل المنسوخة يدويًا ليست إثباتاً بنكياً وتخضع للمراجعة المحاسبية.
- تُنشئ النسخة معرفاً جديداً لكل إرسال يدوي، لذا قد يتكرر إدخال الرسالة نفسها. لا تعتمدها مالياً دون المطابقة.
- لا يُرسل نص SMS نفسه إلى API، بل المبلغ والوقت ومعرف العملية.
- قاعدة الانتظار المحلية SQLite غير مشفرة في النسخة الحالية، وهي تحتوي على مبالغ وتواريخ فقط. لا تستخدمها على هاتف غير موثوق.
- اتصال HTTPS وحده لا يغني عن التحقق من ملكية الخادم والاختبار الأمني المتكامل.
- لم يتم تجميع هذه النسخة أو اختبارها على الهاتف فعلياً في بيئة المساعد.
